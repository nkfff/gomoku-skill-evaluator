# 五子棋 · 棋力评估版

可在浏览器中直接运行的单文件五子棋小游戏，玩家执黑，AI 执白，15×15 自由规则（无禁手）。

## 使用方式

下载 `index.html` 后双击打开即可，无需安装依赖或服务器。

## 功能

- 记录每手落子坐标、思考时间、战术标签和悔棋事件。
- 电脑通过直接胜点判断、必防判断和棋形评分落子。
- 检测直接成五、漏杀、漏防和常见活三、冲四、活四等棋形。
- 生成阶段性或终局棋力报告，可复制内容或导出完整 JSON 棋谱。
- 本地离线运行，棋谱不会自动上传。

## 局限

AI 是启发式对手，不是专业搜索引擎；棋力评分用于自我比较，并非 Elo、业余段位或经过验证的测量结果。棋形识别也无法代替完整的多步 VCF/VCT 分析。

## 后续可扩展

可加入完整博弈搜索、对局分析引擎、分局统计与 GitHub Pages 托管。
