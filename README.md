# 五子棋棋力评估 · Gomoku Skill Evaluator

**正式版：V2.1** | [🎮 在线下棋](https://nkfff.github.io/gomoku-skill-evaluator/) | [旧版 V1](https://nkfff.github.io/gomoku-skill-evaluator/v1/) | [V2.1 独立预览](https://nkfff.github.io/gomoku-skill-evaluator/v2.1/)

这是一个在浏览器里运行的五子棋对战与棋力复盘工具。15 × 15 自由规则，你执黑先手。

## 主要功能

- **AI 对战**：新手、进阶、大师三种难度；胜局分别获得 10、30、80 积分（当前为本地积分）。
- **完整复盘**：记录双方逐手坐标、思考时间，允许跳转历史棋面；给出有限搜索的推荐落点与简要战术评语。
- **V2.1 棋力评估**：Top-1 / Top-3、单步估计损失、严重失误率、局面复杂度加权准确度、关键攻防机会成功率，以及样本可信度。
- **对局生命周期**：终局自动冻结计时、禁止终局后悔棋。
- **皮肤商店**：经典榉木、翡翠、暗夜、樱花、曜金五款棋盘与棋子配色；可用本地积分兑换。
- **JSON 导出**：保存当前有效棋谱、操作事件与分析报告。

## V2.1 评分说明

每手落子使用后台 Worker 进行有限两层的候选着法与对手回应评估：

- **Q**：局面复杂度加权的平均落子准确度（0–100），而非累计关键好手次数。
- **T**：存在明确可处理的直接进攻/防守机会时的成功率（百分制）。
- **E**：在可评分着法中的严重失误率（百分制）。

有战术机会：

```text
分数 = 0.75 × Q + 0.15 × T + 0.10 × (100 − E)
```

无战术机会：

```text
分数 = 0.90 × Q + 0.10 × (100 − E)
```

最后四舍五入并限制 0–100。**对局长短不直接加减分**，它主要通过有效样本量影响「评分可信度」；没有发生关键攻防机会时，对应能力显示「未测得」，不会默认算 0 或 100 分。Top-1 和 Top-3 比例只展示，不直接加分。

**局限：** 搜索并非专业五子棋求解器；Top 排名只针对实际搜索的有限候选着法。评分、局面复杂度与「落子损失」均为启发式指标，不能换算 Elo、段位或真实胜率。

## 本地开发

V2.1 使用 ES Modules，需要通过 HTTP 启动，**不建议直接双击根目录的 `index.html`**：

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

查看 [V2.1 评分开发分支](https://github.com/nkfff/gomoku-skill-evaluator/tree/feature/v2.1-scoring)；测试：

```bash
npm test
```

正式站点由 GitHub Pages 从 `main / (root)` 自动部署。旧版代码在 `v1/index.html`，V2.1 原始预览快照在 `v2.1/`。仓库根目录的 `config.js` 默认不连接云端 API。

## 隐私与积分

未启用云端 API 时，积分、皮肤、昵称与匿名玩家 ID 保存在本浏览器的 `localStorage`，不会自动跨设备同步；清除浏览器网站数据会丢失本地资料。游戏不会在页面内收集或显示原始 IP 地址。

公开部署真正的全球排行榜，仍需完成服务器部署、账户鉴权、反作弊和频率限制。
