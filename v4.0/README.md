# 五子棋 V4.0.12 · 猫猫棋局

V4.0.12 完整升级 PVP 对局生命周期：每回合连续 60 秒未落子弹出 30 秒确认提醒；无响应或主动退出按认输处理；双方同时断线超过 60 秒则中止且不结算 Elo。心跳每 10 秒发送一次，20 秒无响应触发重连。等待房间 30 分钟无活动自动关闭，对局结束后保留 10 分钟供查看结果或再战；双方主动离开则提前清理房间。服务端持久化结果已读状态，棋谱、历史战绩与 Elo 记录独立保留。

同时保留 V4.0.11 的复盘 AI 流式讲解、V4.0.10 的复盘隔离优化，以及原有五子棋规则、10 分钟棋钟、观战、悔棋、和棋申请和 Gunuce 本地神经网络。首次加载资源后可离线对弈，优先 WebGPU、WASM 后备，无推理服务器。

## V4.0.12 · PVP 生命周期与防遗留对局（2026-11-04）

- 每回合连续 60 秒未落子时，服务端触发 30 秒确认弹窗；选择继续后重新计算下一次提醒，选择退出或倒计时结束均按认输结算。
- WebSocket 每 10 秒发送轻量心跳，20 秒无 pong 自动重连；刷新、短暂断网和多标签页替换连接不会直接判负。
- 单方断线给予 60 秒恢复时间，仍未恢复则对手获胜；双方均断线时，从第二名玩家断线起等待完整 60 秒，随后中止本局且不结算 Elo。
- 等待/准备房间 30 分钟无活动自动关闭；结束房间保留 10 分钟用于查看结果和再战，双方均主动返回大厅则提前清理。
- 服务端持久化每位玩家的结果已读状态；已确认的结果不会在下次登录时重复弹出。棋谱、历史结果和 Elo 记录独立保留，不随房间清理删除。
- 新增 D1 迁移文件 0009_pvp_lifecycle.sql，记录“长时间未行动”和“双人断线中止”等细分结束原因。

## 功能

- 暖象牙白、樱花粉和木质棋盘的统一视觉设计；桌面双栏、手机单栏自适应。
- 保留账号、云端积分、主题商店、猫猫棋子、复盘、残局挑战与随机连珠模式。
- AI 对弈支持玩家执黑或执白；引擎搜索、提示、悔棋、复盘和服务器棋谱验证支持动态颜色。
- AI 对弈平局触发幸运猫猫动画；积分按难度胜局基础奖励的 5 倍结算：新手 50、进阶 150、王者 400。
- 真人 PVP 双方准备后由 Worker 使用 Web Crypto 生成骰子点数；同点自动重掷，胜者执黑先手。支持双方弹窗确认和棋、悔棋和再来一局；每局独立结算 Elo 与 D1 棋局记录。
- AI 积分榜与真人 Elo 榜前三分别显示「棋圣、棋王、棋宗」。

## 奖励与排行榜口径

| AI 难度 | 胜局基础奖励 | 平局奖励 |
|---|---:|---:|
| 新手 | 10 | 50 |
| 进阶 | 30 | 150 |
| 王者 | 80 | 400 |

平局奖励只作用于标准 AI 对弈；随机模式没有独立积分奖励，真人 PVP 仍按 Elo 和棋规则结算，避免通过协商和棋刷取 AI 竞技积分。AI 积分榜使用累计竞技积分，消费积分不改变排名。

## 部署前要求

V4.0 复用原有 Cloudflare V2/V3 Worker、D1 数据库与 PVP Durable Object。部署前：

1. 备份 gomoku-v2 D1 数据库。
2. 确认 Supabase URL、Cloudflare API Token、Account ID 与 D1 ID 已配置为 GitHub Actions secrets。
3. 先应用 migrations/ 下所有未执行迁移，再部署 V2 与 V3 Worker。
4. 确认 V2 Worker 返回版本 4.0.0，V3 Worker 返回版本 4.0.0。
5. 使用两个账号验证 PVP 摇骰子、同点重掷、双方颜色一致、对局结算和 Elo 更新。
6. 使用登录账号分别测试三种 AI 难度的平局奖励、断网重试和重复提交，确认每局只入账一次。

真实部署状态以 GitHub Actions 和 Cloudflare Worker 实际响应为准；不能仅凭前端页面显示认定云端结算成功。
