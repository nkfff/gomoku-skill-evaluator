# 五子棋 V4.0.2 · 猫猫棋局

V4.0.2在 V4.0.1 基础上增加好友 PVP 再战与 3D 骰子动画；**Gunuce** 浏览器本地神经网络难度保持不变。首次加载资源后可离线对弈，优先 WebGPU、WASM 后备，无推理服务器。详细部署与测试说明见 [GUNUCE.md](GUNUCE.md)。

V4.0 是在 V3.4 基础上建立的独立版本，保留 V3.4 入口与数据结构，采用新的暖色视觉系统，并升级 AI 先手、平局奖励、PVP 摇骰子与排行榜荣誉。

## 功能

- 暖象牙白、樱花粉和木质棋盘的统一视觉设计；桌面双栏、手机单栏自适应。
- 保留账号、云端积分、主题商店、猫猫棋子、复盘、残局挑战与随机连珠模式。
- AI 对弈支持玩家执黑或执白；引擎搜索、提示、悔棋、复盘和服务器棋谱验证支持动态颜色。
- AI 对弈平局触发幸运猫猫动画；积分按难度胜局基础奖励的 5 倍结算：新手 50、进阶 150、王者 400。
- 真人 PVP 双方准备后由 Worker 使用 Web Crypto 生成骰子点数；同点自动重掷，胜者执黑先手。双方均确认再来一局后，原房间会创建全新对局并重新掷骰；每局独立结算 Elo 与 D1 棋局记录。
- AI 积分榜与真人 Elo 榜前三分别显示「棋圣、棋王、棋宗」。

## 奖励与排行榜口径

| AI 难度 | 胜局基础奖励 | 平局奖励 |
|---|---:|---:|
| 新手 | 10 | 50 |
| 进阶 | 30 | 150 |
| 王者 | 80 | 400 |

平局奖励只作用于标准 AI 对弈；随机模式没有独立积分奖励，真人 PVP 仍按 Elo 和棋规则结算，避免通过协商和棋刷取 AI 竞技积分。AI 积分榜使用累计竞技积分，消费积分不改变排名。

## 部署前要求

V4.0 复用原有 Cloudflare V2/V3 Worker、D1 数据库与 PVP Durable Object。部署前：

1. 备份 gomoku-v2 D1 数据库。
2. 确认 Supabase URL、Cloudflare API Token、Account ID 与 D1 ID 已配置为 GitHub Actions secrets。
3. 先应用 migrations/ 下所有未执行迁移，再部署 V2 与 V3 Worker。
4. 确认 V2 Worker 返回版本 4.0.0，V3 Worker 返回版本 4.0.0。
5. 使用两个账号验证 PVP 摇骰子、同点重掷、双方颜色一致、对局结算和 Elo 更新。
6. 使用登录账号分别测试三种 AI 难度的平局奖励、断网重试和重复提交，确认每局只入账一次。

真实部署状态以 GitHub Actions 和 Cloudflare Worker 实际响应为准；不能仅凭前端页面显示认定云端结算成功。


## V4.0 维护更新（2026-10-30）

- 新增 D1 迁移 `0007_repair_mode_challenges.sql`：修复迁移记录与实际表结构不一致的问题，重建残局挑战表并保留已有挑战记录、奖励与领取状态；未完成旧挑战过期。
- 管理员身份比较统一按去空格、小写 UUID 处理；Supabase 同一用户的 Token 刷新不再隐藏已验证的管理员面板，账号切换时仍先隐藏再由 Worker 重新授权。
- 皮肤收藏卡片改为读取当前棋盘主题色板，深色主题使用对应深色卡片；皮肤名称与价格说明使用独立文字层级和主题对比色。
- 自动化测试增加管理员 UUID 比较和旧版 D1 残局表修复测试。
- 修复 AI 对弈棋力评估固定统计黑棋的问题：统计函数接收 `humanColor`，只汇总玩家实际执棋颜色；实时评分、复盘统计和棋谱 JSON 导出统一使用玩家颜色。
- 新增黑棋、白棋评分隔离、默认参数兼容、非法颜色校验及前端调用点的回归测试。


## V4.0.1 状态栏主题对比修复（2026-11-03）

- 棋盘状态栏背景改为当前棋盘主题的 `--surface`，状态文字使用 `--heading`，辅助文字使用 `--muted`，避免暗夜星河、曜金等深色主题出现浅底浅字。
- 经典、翡翠、暗夜星河、樱花庭院、猫咪咖啡馆、曜金六种主题均通过状态文字与背景的 WCAG AA 对比度（至少 4.5:1）回归测试。
- 更新 Service Worker 缓存版本及离线资源 SHA-256；不修改 AI、积分结算、账号、Worker 或 D1 数据结构。


## V4.0.2 好友 PVP 连续对局与 3D 骰子（2026-11-03）

- 对局结束后出现「再来一局」与「重新匹配」两个操作。
- 「再来一局」采用双方确认机制：一方发起后，对手看到「接受再来一局」；双方都同意后，服务端为原房间创建新的 matchId、清空棋盘与计时器，并重新生成服务端骰子结果。
- 每一局仍独立写入 pvp_matches、独立结算 Elo；不复用上一局棋盘、不重复结算旧对局。
- 「重新匹配」返回好友对战大厅，可创建新房间或输入新的好友邀请码。当前版本仍是邀请码好友房间，没有随机匹配队列。
- 摇骰改为 CSS 3D 六面骰子，包含立体旋转、抛起、落定与点数揭晓；保留服务器生成点数和同点重掷规则。
- 不新增 D1 表或迁移；部署时需要重新部署 V3 PVP Worker 与更新 GitHub Pages 前端。
- 回归测试覆盖双方确认、状态重置、非房间成员拒绝、3D 骰子页面结构与样式。
